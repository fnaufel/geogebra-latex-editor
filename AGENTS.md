# Agent Instructions

## Agent skills

- Before planning, specifications, tickets, or issue work, read [the issue-tracker convention](docs/agents/issue-tracker.md) and [the triage-label convention](docs/agents/triage-labels.md).
- Before changing domain language or architecture, read [the domain-document convention](docs/agents/domain.md), the referenced glossary, and applicable ADRs.
- Before implementing the first release, read the accepted specification under `docs/specs/` in full.
